# Portal Screenshot - Requirements

## Image File
**Target**: `portal-screenshot.png`

## Usage
**Location**: Any Portal slide
**Purpose**: Show actual Octo Portal interface

## Visual Requirements

### Content
- **Type**: Screenshot of actual Octo Portal interface
- **View**: Catalog view showing components
- **Style**: Real interface, optionally annotated

### Screenshot Requirements
- **Interface Elements to Show**:
  - Navigation sidebar
  - Component catalog list
  - Component cards with metadata
  - Search/filter functionality
  - Breadcrumbs or hierarchy navigation

### Optional Annotations
- **Callouts**: Highlight key features
- **Arrows**: Point to important elements
- **Labels**: Add explanatory text
- **Highlights**: Emphasize specific areas

### Annotation Style (if used)
- **Callout Boxes**: Rounded rectangles with arrows
- **Colors**: Use accent colors (`#0f3460`, `#51cf66`)
- **Text**: Clear, concise labels
- **Arrows**: Modern, clean arrow style

## Technical Specifications
- **Format**: PNG
- **Resolution**: 1920x1080 (16:9 aspect ratio) or native resolution
- **File Size**: < 2MB
- **Background**: Actual interface background

## Design Notes
- Use real, authentic screenshot (not mockup)
- Ensure text is readable
- Remove sensitive data if needed
- Show representative components
- Professional appearance
